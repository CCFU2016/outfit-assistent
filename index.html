Automatisch erkennen

Claude erkennt auf deinen Fotos Kategorie, Farbe, Wärme und einen Namen. Du kannst danach alles ändern. Das Foto wird dafür an unseren Server und an Claude (Anthropic) geschickt. Unser Server speichert es nicht.

Sicherung

Deine Stücke sind nur auf diesem Handy gespeichert. Mit einer Sicherung gehen sie nicht verloren, auch nicht bei einem neuen Handy.

iPhone: Im Teilen-Menü auf „In Dateien sichern“ tippen, z. B. in iCloud Drive.
Android: Die Datei landet im Ordner „Downloads“.
